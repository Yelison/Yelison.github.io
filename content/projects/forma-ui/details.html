Inside the project

The problem

The components built for Resolve deserved to live on their own, with a documented contract between design and code.

My contribution

Extracting the library from Resolve: semantic design tokens, light, dark and system themes, accessible components and a bilingual documentation site.

A technical decision

Tokens start as Figma variables and are exported to code, so design and implementation share one source. The library is still in development, and its plan is public in the repository.
