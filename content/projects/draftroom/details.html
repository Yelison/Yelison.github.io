Inside the project

The problem

People writing the same document at once need to see each other, trust that their work is saved and keep writing when the connection drops.

My contribution

Built it end to end: the React and Tiptap editor, the Fastify API, the real-time collaboration server over PostgreSQL, the Docker deployment and tests with two real browsers against the real server.

A technical decision

“Synced” means stored: the editor only says it once the server confirms the change is in the database, never because the local copy changed. Edits made offline wait in the browser and are sent when the connection returns.
