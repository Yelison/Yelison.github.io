Inside the project

The problem

Support teams need tickets, customers, reports and a knowledge base in one place, with an interface that stays usable on any screen.

My contribution

Built it end to end from a complete Figma design: the React frontend, the Spring Boot API, the PostgreSQL schema and the pipeline.

A technical decision

The API is contract-first: an OpenAPI file is the single source of truth, backend tests validate every response against it and the frontend generates its typed client from it. Tickets carry an ETag, so a stale edit is rejected instead of overwriting someone else’s change.
